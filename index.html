        ¿Cómo funciona Radar TIC?

        Un agente persigue un objetivo y decide usar herramientas. Aquí el objetivo es investigar; la herramienta es Web Search.

        Navegadorindex.html · assets/
        POST /api/investigar
        FastAPIapp/main.py
        InvestigacionRequest
        InvestigadorServiceapp/services
        Responses API + web_search
        OpenAIInternet

        index.html + assets/css

        Estructura semántica y presentación visual separadas.

        assets/js

        config.js decide el endpoint, api.js encapsula HTTP y app.js controla eventos y estados.

        app/main.py

        Coordina la capa web: frontend, estáticos, CORS y endpoints. No contiene la lógica del agente.

        app/core/config.py

        Lee OPENAI_API_KEY y el modelo desde variables de entorno, solo en el servidor.

        app/models/investigacion.py

        Valida la pregunta, el modo y la forma exacta del reporte con Pydantic.

        app/services/investigador_service.py

        Construye instrucciones, llama a Responses API con Web Search y procesa reporte, citas y fuentes.

        La API Key nunca llega al navegador

        En local vive en .env (ignorado por Git); en Vercel, como variable de entorno del proyecto. El frontend solo conoce /api/investigar; /api/health informa si la clave existe, nunca su valor.
